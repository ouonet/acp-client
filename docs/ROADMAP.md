# Roadmap: VS Code ACP Client Extension

- [x] M1: 核心 ACP 协议与进程/会话引擎 (Headless Core: ProcessManager, SessionHub, StorageManager, 单元测试套件)
- [x] M2: 可视化配置中心与沉浸式多会话 Webview (Agent 配置与连接测试 UI、多 Session 切换、精细流式/Thinking 渲染、输入历史、二合一 Send/Stop 按钮、多模态附件)
- [x] M3: 细粒度 Diff 审查、安全权限审批与双模原生 Chat 融合 (文件修改 Diff 对比写入、终端命令审批、VS Code Chat Participant `@acp` 桥接)
- [x] M4: UI 布局精细化与专业图标系统升级 (现代输入卡片底置工具条、多行自增高、SVG 专业图标库、插件品牌图标)
